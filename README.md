## 下载

请前往 [Releases 页面](https://github.com/cjd0901/yingfeng-data-releases/releases/latest) 下载最新版本。

| 系统 | 适用设备 | 推荐文件 |
|---|---|---|
| Windows | Windows 10/11 64 位 | 文件名包含 `setup.exe` |
| Windows | 企业部署或管理员安装 | `.msi` 文件 |
| macOS Apple Silicon | M1、M2、M3、M4 及更新芯片 | 文件名包含 `aarch64` 或 `arm64` 的 DMG |
| macOS Intel | Intel 处理器的 Mac | 文件名包含 `x64` 的 DMG |

如果不确定 Mac 的芯片类型，可点击屏幕左上角的苹果菜单，选择“关于本机”查看。

## Windows 安装

1. 下载文件名包含 `setup.exe` 的安装程序。
2. 双击安装。
3. 安装完成后，从桌面或开始菜单打开“迎风数据”。

如果 Windows 显示未知发布者提示，请确认安装包来自本仓库的 Releases 页面后再决定是否继续。

## macOS 安装

1. 根据芯片类型下载对应的 DMG。
2. 打开 DMG。
3. 将“迎风数据”拖入“应用程序”文件夹。
4. 从“应用程序”中打开。

## 运行要求

- Windows 10/11 64 位，或受支持的 macOS
- 已安装 Microsoft Edge 或 Google Chrome
- 可以正常访问目标地图及商家网站
- 部分功能或使用额度可能需要激活码，具体以应用内提示为准
